Visual path: what can it claim?

Throwaway planning prototype. Switch cases and inspect where an observed ICMP reply stops and an interpretation begins. This is not application code or a final UI design.

Reading rule: Each numbered row is one ICMP request sent with that hop limit to the selected final-host IP. A reply identifies its responding address and round-trip time. The line between rows is reading order, not a verified physical link or proof of the route taken by HTTP.

    Separate evidence

    Gateway measurement, when available, is shown separately from the hop sequence; the first responding hop is not automatically the default gateway. IPv4 and IPv6 receive separate paths and outcomes.

    What to decide

    Is “observed ICMP replies toward the selected IP” a clear enough title? Is a numbered list preferable to a connected route diagram? Should an apparent latency rise be shown only as raw RTTs, or also highlighted with an explicit caution? Should optional ASN ownership sit inline or behind details?
